Design boundary

What can actually improve K3 on ordinary hardware

Multi-tier cache

Keep popular experts in VRAM, then RAM, with SSD as the immutable backing store. Gain depends on measured expert locality.

Asynchronous prefetch

Overlap expert reads with CPU/GPU work. It hides latency only when useful computation is long enough.

Speculative verification

Draft several tokens cheaply and let exact K3 verify them together. It remains exact, but only if the draft avoids K3’s full expert cost.

Several ordinary PCs

Pool storage and memory through topology-aware sharding. Exact K3 needs a new tested worker protocol; it is not falsely marked complete here.

Adaptive quality

Reduce precision or routed experts for speed. This can be useful, but it is no longer numerically identical to official K3.

Smaller surrogate

The credible interactive path on a 32 GB laptop. It may imitate the workflow, but it must never be represented as the official 2.8T model.
