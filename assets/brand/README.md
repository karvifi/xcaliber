# Xcaliber brand assets

Xcaliber's visual language combines a calibrated X with sparse compute-routing nodes.
The lime rail represents measured capacity; the cyan rail represents execution. Their
intersection is the decision point where Xcaliber chooses an honest local mode.

## Files

- `xcaliber-mark.svg` — square product mark and icon source.
- `xcaliber-wordmark.svg` — horizontal wordmark on a dark surface.
- `xcaliber-readme.svg` — repository and documentation banner.
- `xcaliber-compute-field.png` — original wide brand artwork generated for Xcaliber.
- `../screenshots/xcaliber-overview.png` — desktop overview with deterministic preview data.

## Core colors

| Name | Hex | Use |
|---|---|---|
| Graphite | `#080B0D` | Primary background |
| Surface | `#11191D` | Cards and installer surfaces |
| Caliber lime | `#B9FF66` | Capacity, safe actions, source rail |
| Execution cyan | `#5DE4FF` | Runtime state, output rail |
| Frost | `#F1F7F8` | Primary text |
| Steel | `#85969E` | Secondary text |

Do not stretch, rotate, recolor, outline, or place the mark over a busy image without
an opaque graphite container. Keep clear space around the mark equal to the width of
its center diamond. The assets are part of Xcaliber and are licensed under the
repository's AGPL-3.0-only license.
